# Built in Commands
YShared comes with several built-in commands to help with getting started.

| Command | Description |
| --- | --- |
| `clear` | Clear the console output. |
| `help (page:int)` | Prints all commands, their usage format and brief description to the console. |
| `help (cmd:Command)` | Shows the manual of a specific command. |
| `screenshot` | Take a screenshot and save it to your clipboard.|
| `yconsole fontsize` | Change the font size of the console. |
| `yconsole unity_console info` | Toggle whether regular Unity Console messages (such as through `Debug.Log`) are visible in YConsole. Defaults to `True`. |
| `yconsole unity_console warnings` | Toggle whether regular Unity Console messages (such as through `Debug.LogWarning`) are visible in YConsole. Defaults to `False`. |
| `yconsole unity_console errors` | Toggle whether regular Unity Console messages (such as through `Debug.LogError`) are visible in YConsole. Defaults to `True`. |
